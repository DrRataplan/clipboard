Inspect

Paste into the box (Ctrl+V / Cmd+V) or read the clipboard directly — every MIME type is shown with its content.

Write

Queue MIME types and content below, edit, then write. Queuing a type that is already queued updates that row. Text is written as a Blob of its type; use a data: URL for binary (e.g. image/png).

Browser reality check: Chrome only accepts text/plain, text/html, image/png and custom web … formats; Safari writes HTML as web text/html. Vendor types like application/vnd.fontoxml need the web  prefix in Chrome. Unsupported types throw — watch the log.
